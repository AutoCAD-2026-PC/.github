# Performance

AutoCAD performance depends on drawing complexity, object count, external references, 3D geometry, graphics hardware, available memory, and storage performance.

Organized layers, optimized blocks, clean drawings, and appropriate graphics settings can improve responsiveness in larger projects.

---

# Troubleshooting

If AutoCAD becomes slow or unstable, review drawing complexity, graphics drivers, external references, plugins, available memory, and background applications.

For problematic DWG files, check referenced resources, drawing integrity, fonts, and project configuration.

Maintain independent backups and incremental versions of important CAD projects.
